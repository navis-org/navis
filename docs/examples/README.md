# Tutorials

Worked examples that take you from loading your first neuron all the way to
plotting, morphological analysis, NBLAST and machine learning. Every tutorial is a
self-contained script you can read here or download and run yourself.

!!! tip "New to NAVis?"
    Start with **[The Basics](tutorial_basic_00_basics)** and work your way down.
