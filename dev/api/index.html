    API Overview#

    NAVis has grown a lot! Last I looked, there were over 120 functions and classes exposed at top level (e.g. navis.plot3d) and easily another 100 available via submodules (e.g. navis.transforms.AffineTransform). This can be a bit daunting at first - especially if you don't exactly know what you are looking for!

    This document provides a curated, high-level summary. I recommend you either just have a browse, use the search field (upper right) or simply search in page (CONTROL/CMD-F). Failing that, please feel free to open a thread on Github Discussions with your question.

    This API reference is a more or less complete account of the primary functions:

    1. Neuron- and NeuronList functions and methods
    2. Functions for visualization
    3. Manipulate or analyze neuron morphology
    4. Transforming and mirroring data
    5. Analyze connectivity
    6. Import/Export
    7. Utility functions
    8. Which functions work with which neuron types?

    In addition NAVis has interfaces to various external datasets and tools:

    • NEURON simulator
    • Neuromorpho
    • neuPrint
    • InsectBrain DB
    • Blender 3D
    • Cytoscape
    • Allen MICrONS datasets

    Most of these functions include examples of how to use them. Click on them to learn more!

    Neurons & NeuronLists#

    Skeletons, Meshes, Voxels and Dotprops are neuron classes. NeuronLists are containers thereof.

    Class Description
    navis.Skeleton Skeleton representation of a neuron.
    navis.Mesh Meshes with vertices and faces.
    navis.Voxels 3D images (e.g. from confocal stacks).
    navis.Dotprops Point cloud + vector representations, used for NBLAST.
    navis.NeuronList Containers for neurons.

    General Neuron methods#

    Despite being fundamentally different data types, all neurons share some common methods (i.e. functions) which they inherit from their abstract parent class BaseNeurons.

    Method Description
    Neuron.copy() Return a copy of the neuron.
    Neuron.plot3d() Plot neuron using navis.plot3d.
    Neuron.plot2d() Plot neuron using navis.plot2d.
    Neuron.summary() Get a summary of this neuron.
    Neuron.convert_units() Convert coordinates to different unit.
    Neuron.map_units() Convert units to match neuron space.
    Neuron.memory_usage() Return estimated memory usage of this neuron.
    Neuron.mask() Restrict this neuron to part of itself.
    Neuron.unmask() Undo the innermost mask, in place.
    Neuron.apply_mask() Make the innermost mask permanent.

    In addition to methods, neurons also have properties. These properties common to all neurons:

    General Neuron properties#

    Property Description
    Neuron.connectors Connector table. If none, will return None.
    Neuron.postsynapses Table with postsynapses (filtered from connectors table).
    Neuron.presynapses Table with presynapses (filtered from connectors table).
    Neuron.datatables Names of all DataFrames attached to this neuron.
    Neuron.id ID of the neuron.
    Neuron.name Neuron name.
    Neuron.units Units for coordinate space.
    Neuron.type Neuron type.
    Neuron.soma The soma of the neuron (if any).
    Neuron.bbox Bounding box of neuron.

    Note

    Neurons can have the above properties but that is not guaranteed. For example, a neuron might not have any associated synapses in which case Neuron.connectors will be None.

    Skeletons#

    A navis.Skeleton represents a skeleton. These are class methods available specific for this neuron type. Note that most of them are simply short-hands for the other NAVis functions:

    Method Description
    Skeleton.convert_units() Convert coordinates to different unit.
    Skeleton.cell_body_fiber() Prune neuron to its cell body fiber.
    Skeleton.downsample() Downsample the neuron by given factor.
    Skeleton.get_graph_nx() Calculate and return networkX representation of neuron.
    Skeleton.get_igraph() Calculate and return iGraph representation of neuron.
    Skeleton.prune_by_longest_neurite() Prune neuron down to the longest neurite.
    Skeleton.prune_by_strahler() Prune neuron based on Strahler order.
    Skeleton.prune_by_volume() Prune neuron by intersection with given volume(s).
    Skeleton.prune_distal_to() Cut off nodes distal to given nodes.
    Skeleton.prune_proximal_to() Remove nodes proximal to given node. Reroots neuron to cut node.
    Skeleton.prune_twigs() Prune terminal twigs under a given size.
    Skeleton.reload() Reload neuron. Must have filepath as .origin as attribute.
    Skeleton.reroot() Reroot neuron to given node ID or node tag.
    Skeleton.resample() Resample neuron to given resolution.
    Skeleton.snap() Snap xyz location(s) to closest node or synapse.

    In addition, a navis.Skeleton has a range of different properties:

    Method Description
    Skeleton.adjacency_matrix Adjacency matrix of the skeleton.
    Skeleton.cable_length Cable length.
    Skeleton.cycles Cycles in neuron (if any).
    Skeleton.downsample Downsample the neuron by given factor.
    Skeleton.edges Edges between nodes.
    Skeleton.edge_coords Coordinates of edges between nodes.
    Skeleton.igraph iGraph representation of this neuron.
    Skeleton.is_tree Whether neuron is a tree.
    Skeleton.n_branches Number of branch points.
    Skeleton.n_leafs Number of leaf nodes.
    Skeleton.n_skeletons Number of seperate skeletons in this neuron.
    Skeleton.n_trees Count number of connected trees in this neuron.
    Skeleton.nodes Node table.
    Skeleton.root Root node(s).
    Skeleton.sampling_resolution Average cable length between child -> parent nodes.
    Skeleton.segments Neuron broken down into linear segments (see also .small_segments).
    Skeleton.simple Simplified representation consisting only of root, branch points and leafs.
    Skeleton.soma_pos Search for soma and return its position.
    Skeleton.subtrees List of subtrees. Sorted by size as sets of node IDs.
    Skeleton.vertices Vertices of the skeleton.
    Skeleton.volume Radius-based volume.

    Skeleton utility functions#

    Function Description
    navis.rewire_skeleton() Rewire neuron from graph.
    navis.insert_nodes() Insert new nodes between existing nodes.
    navis.remove_nodes() Drop nodes from neuron without disconnecting it.
    navis.collapse_nodes() Collapse group of nodes into a single node.
    navis.graph.simplify_graph() Simplify skeleton graph (networkX or igraph).
    navis.graph.skeleton_adjacency_matrix() Generate adjacency matrix for a skeleton.

    Voxel neurons#

    Voxels (e.g. from confocal image stacks) are a relatively recet addition to NAVis and the interface might still change.

    These are methods and properties specific to Voxels:

    Property Description
    Voxels.centroid Centre of mass of the neuron, in units (i.e. including the offset).
    Voxels.closing() Dilate, then erode: bridges narrow gaps and fills small pits.
    Voxels.connected_components() Label the neuron's connected components.
    Voxels.densify() Convert to a dense grid representation.
    Voxels.density Fraction of filled voxels.
    Voxels.dice() Dice coefficient (F1 score) with other.
    Voxels.difference() Voxels in this neuron but not in other (set subtraction).
    Voxels.dilate() Grow the neuron by its voxel neighbourhood.
    Voxels.distance_transform() Distance from each voxel to the nearest background voxel.
    Voxels.erode() Shrink the neuron by peeling voxels that touch the background.
    Voxels.fill_cavities() Fill enclosed background voids.
    Voxels.grid Voxel grid representation.
    Voxels.intersection() Voxels present in this neuron and in every one of the others.
    Voxels.iou() Intersection over union (Jaccard index) with other.
    Voxels.max Maximum value (excludes zeros).
    Voxels.mesh() Convert this neuron into a mesh.
    Voxels.min Minimum value (excludes zeros).
    Voxels.nnz Number of non-zero voxels.
    Voxels.offset Offset in units (not voxels), i.e. the position of voxel (0, 0, 0).
    Voxels.opening() Erode, then dilate: strips specks and thin spurs, keeps bulk shape.
    Voxels.shape Shape of voxel grid.
    Voxels.skeletonize() Convert this neuron into a skeleton.
    Voxels.sparsify() Convert to a sparse voxel representation.
    Voxels.strip() Strip empty voxels (leading/trailing planes of zeros).
    Voxels.surface_area Area of the neuron's exposed (blocky, staircase) surface.
    Voxels.symmetric_difference() Voxels in exactly one of this neuron and other (set XOR).
    Voxels.thin() Thin the neuron to a one-voxel-wide medial curve (centerline).
    Voxels.threshold() Drop below-threshold voxels.
    Voxels.union() Voxels present in this neuron or any of the others.
    Voxels.voxels Voxels making up the neuron.

    Dotprops#

    navis.Dotprops are typically indirectly generated from e.g. skeletons or point clouds using navis.make_dotprops().

    These are methods and properties specific to Dotprops:

    Function Description
    Dotprops.points Center of tangent vectors.
    Dotprops.vect Tangent vectors.
    Dotprops.alpha Alpha values for tangent vectors.
    Dotprops.to_skeleton() Turn Dotprop into a Skeleton.
    Dotprops.snap() Snap xyz location(s) to closest point or synapse.

    Converting between types#

    These functions will let you convert between neuron types:

    Function Description
    navis.make_dotprops() Produce dotprops from neurons or point clouds.
    navis.skeletonize() Turn neuron into skeleton.
    navis.mesh() Generate mesh from object(s).
    navis.voxelize() Turn neuron into voxels.
    navis.conversion.voxels2mesh() Generate mesh from voxels.
    navis.conversion.voxels2skeleton() Turn voxels into a skeleton.
    navis.conversion.tree2meshneuron() Convert Skeleton to Mesh.

    See also Utility for functions to convert to/from basic data types.

    NeuronList methods#

    NeuronLists let you access all the properties and methods of the neurons they contain. In addition there are a few NeuronList-specific methods and properties.

    Methods:

    Method Description
    NeuronList.apply() Apply function across all neurons in this NeuronList.
    NeuronList.head() Return summary for top N neurons.
    NeuronList.itertuples() Helper to mimic pandas.DataFrame.itertuples().
    NeuronList.mean() Return mean numeric and boolean values over all neurons.
    NeuronList.remove_duplicates() Remove duplicate neurons from list.
    NeuronList.sum() Return sum numeric and boolean values over all neurons.
    NeuronList.summary() Get summary over all neurons in this NeuronList.
    NeuronList.tail() Return summary for bottom N neurons.
    NeuronList.unmix() Split into NeuronLists of the same neuron type.

    Properties:

    Property Description
    NeuronList.bbox Bounding box across all neurons in the list.
    NeuronList.empty Return True if NeuronList is empty.
    NeuronList.id An array with the IDs of the neurons contained in the list.
    NeuronList.idx An indexer similar to pandas' iloc that accepts neuron IDs.
    NeuronList.is_degenerated Return True if contains neurons with non-unique IDs.
    NeuronList.is_mixed Return True if contains more than one type of neuron.
    NeuronList.pipeline Start a navis.Pipeline bound to this NeuronList.
    NeuronList.shape Shape of NeuronList (N, ).
    NeuronList.types Return neuron types present in this list.

    Please see the tutorial on NeuronList for more information, including how to index them.

    Pipelines#

    Chaining functions over a NeuronList with parallel=True sends the neurons to a worker and back once per function. A navis.Pipeline fuses consecutive per-neuron steps into a single task so they make that trip once for the whole chain, and lets each step modify the intermediate the previous one produced instead of taking its own copy.

    Class Description
    navis.Pipeline A reusable, composable sequence of operations.
    Pipeline.add() Add a step and return the new pipeline.
    Pipeline.add_each() Add a step that is mapped over the elements of the value.
    Pipeline.add_once() Add a step that is called once, with the whole value.

    See the multiprocessing tutorial for how they compare to plain parallel=True.

    Various functions for plotting neurons and volumes.

    Function Description
    navis.plot3d() Generate interactive 3D plot.
    navis.plot2d() Generate 2D plots of neurons and neuropils.
    navis.plot1d() Plot neuron topology in 1D according to Cuntz et al. (2010).

    navis.clear3d() Clear viewer 3D canvas.
    navis.close3d() Close and forget existing 3D viewer.
    navis.pop3d() Remove the last item added to the 3D canvas.
    navis.get_viewer() Grab active 3D viewer.

    Plotting Volumes/Meshes#

    To plot meshes, you can pass trimesh.Trimesh objects directly to plot3d() or plot2d(). However, NAVis has a custom class to represent meshes that has some useful perks: navis.Volume.

    Class Description
    navis.Volume Mesh consisting of vertices and faces.
    navis.Volume.combine Merge multiple volumes into a single object.
    navis.Volume.plot3d Plot volume using navis.plot3d.
    navis.Volume.validate Use trimesh to try and fix issues (holes/normals).
    navis.Volume.resize Resize volume.

    Octarine 3D viewer#

    Using navis.plot3d() with backend="octarine" from a terminal will return an octarine.Viewer 3D viewer. Please see the Octarine documentation for details about the viewer.

    The viewer is also stashed away so that you don't have to hold on to it yourself: navis.get_viewer() hands it back to you, and navis.clear3d(), navis.pop3d() and navis.close3d() operate on it directly.

    The TemplateRegistry keeps track of template brains, transforms and such:

    Class Description
    navis.transforms.templates.TemplateRegistry Tracks template brains, available transforms and produces bridging sequences.

    The relevant instance of this class is navis.transforms.registry. So to register and use a new transform you would look something like this:

    >>> transform = navis.transforms.AffineTransform(...)
>>> navis.transforms.registry.register_transform(transform,
...                                              source='brainA',
...                                              target='brainB')
>>> xf = navis.xform_brain(data, 'brainA', 'brainB')

    You can check which transforms are registered like so:

    >>> navis.transforms.registry.summary()  # this outputs a dataframe

    Network Models#

    NAVis comes with a simple network traversal model (used in Schlegel, Bates et al., 2021).

    BayesianTraversalModel is a fast, deterministic approximation of the Monte-Carlo TraversalModel. It is exact for tree-like graphs and single points of reconvergence (e.g. diamonds) but still assumes a node's parents are traversed independently; use TraversalModel as ground truth when a node's parents share correlated upstream ancestry.

    Not imported at top level! Must be imported explicitly:

    from navis import models
    Class Description
    navis.models.TraversalModel Model for traversing a network starting with given seed nodes.
    navis.models.BayesianTraversalModel Model for traversing a network starting with given seed nodes.
